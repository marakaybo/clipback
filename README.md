# Clipback

Лёгкая программа для Windows, которая всё время держит в памяти последние минуты экрана и звука и сохраняет их по горячей клавише — как «Мгновенный повтор» NVIDIA, только с обрезкой прямо в программе: выделил нужные секунды и сохранил только их.

*A lightweight Windows replay buffer: keeps the last minutes of your screen and sound in memory, saves them on a hotkey, and lets you trim the clip right away.*

## Скачать

На странице [Releases](../../releases/latest) два варианта:

- **`Clipback-*-setup.exe`** — установщик. Ставится в профиль пользователя без прав администратора, создаёт ярлыки в «Пуске» и на рабочем столе, удаляется через «Приложения» Windows
- **`Clipback-*-portable.exe`** — portable-версия одним файлом: положите в любую папку и запускайте

Обе версии обновляются из самой программы: «Настройки → Программа → Обновления». Clipback проверяет новую версию при запуске и только сообщает о ней — скачивает лишь по вашей кнопке. Каждое обновление подписано, программа проверяет подпись перед установкой.

Требуется Windows 10/11 (64-бит) с WebView2 (в Windows 11 уже есть) и видеокарта с аппаратным кодированием H.264 (NVIDIA, AMD, Intel). Windows может показать предупреждение SmartScreen, потому что программа не подписана сертификатом: «Подробнее» → «Выполнить в любом случае».

Горячие клавиши по умолчанию: `Alt+F10` — сохранить последние минуты, `Alt+F9` — начать / остановить запись, `Alt+Z` — оверлей, `Alt+F1` — скриншот. Всё меняется в настройках.

## Возможности

- **Буфер последних минут** (от 30 секунд до 20 минут) в оперативке, сохранение по `Alt+F10`
- **Полноценная запись** по `Alt+F9` или кнопке «Запись»: пишется сразу в файл, без ограничения по длине, со всеми дорожками звука
- **Оверлей поверх игры** по `Alt+Z`: клипы, плеер, обрезка — без сворачивания игры (в режиме «Без рамки»)
- **Полноценное окно** с тем же редактором, работа в фоне из трея
- **Просмотр во весь экран** (`F` или двойной щелчок), покадровый шаг `,` / `.`, замедление 0.25× и 0.5×
- **Обрезка**: «Оригинал» — мгновенно и без потерь; «Высокое / Среднее / Низкое» — перекодирование на видеокарте в 1440p / 1080p / 720p, точно по кадру и в несколько раз легче
- **Звук отдельными дорожками** с формой волны на таймлайне — любую можно выключить при сохранении отрезка:
  - обычный режим: «Звук системы» и «Микрофон» (плюс служебная «Всё вместе» первой — её играют плееры и Discord)
  - расширенный режим: ещё и отдельная дорожка на каждое выбранное приложение (Discord, игра, музыка) — как «Захват звука приложения» в OBS
- **Микрофон**: выбор устройства, индикатор уровня, усиление, подсказка, если в Windows он выключен или тихий
- **Качество записи**: экономное / среднее / высокое или свой битрейт, с подсказкой «сколько мегабайт за минуту»
- **Скриншоты**: экрана по `Alt+F1` и любого кадра из клипа
- **Редактор скриншотов** (`E`): карандаш, маркер, стрелка, рамка, текст, пикселизация (скрыть ник или чат) и обрезка; отмена `Ctrl+Z`, сохранение копией или поверх оригинала
- **Имя игры в названии файла**: «Battlefield 6 2026-10-15 21-48-03.mp4»
- **Копирование файла** в буфер обмена — `Ctrl+V` в Discord или Telegram
- Удаление в корзину, переименование, автозапуск с Windows

## Почему лёгкая

- Захват, перевод цвета и кодирование идут на видеокарте (NVENC / AMF / QuickSync) — около 0,2 % процессора при 1440p60
- Ничего не встраивается в игру: картинка берётся системным захватом экрана Windows (DXGI Desktop Duplication), поэтому античиты на программу не реагируют
- Буфер хранится уже сжатым, сохранение — просто запись готовых кадров в MP4
- Повышенный приоритет на видеокарте (как у OBS и ShadowPlay): игра, грузящая видеокарту на 100 %, не отнимает кадры у записи

## Сборка

Нужен [Rust](https://rustup.rs) (stable, `x86_64-pc-windows-msvc`) и Windows 10/11 с WebView2 (есть в Windows 11).

```
cd app
cargo build --release
```

Готовая программа: `app/target/release/clipback.exe`.

Релиз (установщик, portable и `latest.json` для обновлений) собирает `scripts/release.ps1`, ему нужен [Tauri CLI](https://v2.tauri.app) (`cargo install tauri-cli --version "^2"`) и ключ подписи обновлений — подробности в начале скрипта. Консольная версия ядра без интерфейса: `cd core && cargo build --release` → `core/target/release/clipback.exe --help`.

## Тесты

```
cd core && cargo test --release                       # 42 теста ядра
cd core && cargo test --release -- --ignored          # запись на настоящей видеокарте
cd app  && cargo test                                 # настройки и работа с файлами
node ui/tests/names.test.js ui/app.js                 # разбор имён клипов
node ui/tests/montage.test.js                         # куски монтажа, отмена, время монтажа ↔ исходника
```

Интерфейс можно открыть и в обычном браузере (`ui/index.html` через любой локальный сервер) — он запустится с демо-данными.

## Устройство

```
core/        ядро на Rust
  capture.rs   захват монитора (DXGI Desktop Duplication)
  convert.rs   BGRA → NV12 на видеокарте (D3D11 Video Processor)
  encoder.rs   аппаратный H.264 через Media Foundation
  audio.rs     звук через WASAPI: системный (loopback) и микрофон
  mixer.rs     сведение и кодирование дорожек AAC
  ring.rs      кольцевой буфер последних минут
  mux.rs       запись и обрезка MP4 без перекодирования
  live.rs      полноценная запись в файл по мере кодирования
  recorder.rs  всё вместе: команды и события
app/         приложение на Tauri: окна, оверлей, трей, горячие клавиши, обновление
ui/          интерфейс (HTML/CSS/JS без сборщика), editor.js — редактор скриншотов
scripts/     сборка релиза
```

Журнал работы: `%LOCALAPPDATA%\io.github.clipback\logs\clipback.log`. Настройки: `%APPDATA%\io.github.clipback\settings.json`.

## Известные ограничения

- В «настоящем» эксклюзивном полноэкранном режиме оверлей поверх игры не виден — поставьте в игре «Без рамки» (почти все игры так и работают)
- Начало отрезка сдвигается к ближайшему ключевому кадру (не больше чем на секунду раньше)
- Пока идёт полноценная запись, файл называется `.part` — оглавление MP4 дописывается при остановке. Если компьютер выключится посреди записи, такой файл не откроется
- Запись отдельного окна и курсора — в планах
